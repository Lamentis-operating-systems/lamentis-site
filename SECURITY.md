# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues. Use this
repository's **Private vulnerability reporting** feature so maintainers can
assess and resolve the issue before it is disclosed.

Include a clear description, affected component or version, reproduction steps,
impact, and any proof of concept that is safe to share.

## Supported versions

Security fixes are applied to the current `main` branch. Older deployments
should be updated to the latest supported release.

## Disclosure

We will acknowledge reports, assess severity and impact, work on a fix, and
coordinate disclosure with the reporter where appropriate.
